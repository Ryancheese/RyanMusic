# RyanMusic Releases

本仓库仅存放 **RyanMusic 公开安装包**，供用户下载与应用内自动更新。

源码在私有仓库维护，此处不包含源代码。

## 下载

打开 [Releases](https://github.com/Ryancheese/RyanMusic-Releases/releases/latest) 获取最新版：

| 平台 | 文件 |
|------|------|
| macOS Apple Silicon | `RyanMusic-mac-arm64.dmg` |
| macOS Intel | `RyanMusic-mac-x64.dmg` |
| Windows | `RyanMusic-Setup-x64.exe` |
| Android | `RyanMusic-android.apk` |

## 自动更新

桌面版应用内「检查更新」会读取本仓库的最新 Release，无需登录 GitHub。
